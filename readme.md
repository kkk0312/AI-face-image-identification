## 📌 项目背景

随着AI生成技术（尤其是图像生成）的飞速发展，StyleGAN、DALL-E、Stable Diffusion等模型能够生成高度逼真的图像，这带来了严重的信息安全与内容真实性挑战：
- 虚假信息传播门槛降低，误导公众认知
- 版权保护面临新难题，原创内容易被仿冒
- 传统鉴别方法泛化能力差，难以应对新型生成模型

本项目旨在构建一个高精度、强泛化的AI生成图像鉴别系统，能够有效识别不同模型生成的图像，为内容真实性提供技术保障。


## 🌟 核心特性

### 🔍 多模型泛化鉴别
- 突破单一模型局限，对GAN、扩散模型等多种生成方式具有良好识别能力
- 针对AI生成图像的空域伪影与频域特征差异进行专项优化
- 解决传统方法跨模型泛化能力差的关键问题

### 🚀 高效特征提取
- 采用ConvNeXt作为核心特征提取器，融合CNN与Transformer优势
- 精准捕捉AI生成图像特有的细微特征与模式
- 预处理流程自动化，降低人工干预需求

### 🎯 高精度分类架构
- "预训练特征提取器+MLP分类器"的解耦架构，提升模型泛化能力
- 多层感知机结合Dropout与L2正则化，有效防止过拟合
- 优化的超参数配置，在各类测试集上保持高准确率

### 📊 自动化分析流程
- 从图像输入到结果输出的全流程自动化处理
- 支持批量处理与CSV格式结果导出
- 详细的中间过程日志，便于调试与优化

## 🛠️ 技术架构

**核心技术栈**：
- 特征提取：ConvNeXt预训练模型
- 分类器：多层感知机(MLP)
- 深度学习框架：PyTorch 2.4.1+cu124
- 部署方式：本地运行 | Docker容器化

**鉴别流程**：
1. 图像预处理 → 2. ConvNeXt特征提取 → 3. MLP分类器鉴别 → 4. 结果输出与保存

## 🔍 模型原理与创新点

### 🧠 核心原理
系统采用"预训练特征提取器+分类器"的解耦架构：
- 特征提取阶段：使用未经专门训练的ConvNeXt模型，保留其原始特征提取能力
- 分类阶段：采用MLP分类器，通过包含AI生成图像的训练集进行专门训练

这种架构有效避免了传统模型过度依赖特定生成算法"指纹"的问题，显著提升了跨模型泛化能力。

### 💡 创新点
1. **架构创新**：提出"预训练特征提取器+分类器"模式，将特征提取与分类任务解耦，提升泛化能力
2. **模型创新**：采用ConvNeXt作为特征提取器，相比CLIP:ViT等模型提供更丰富有效的特征表示
3. **分类器优化**：设计四层MLP分类器，结合Dropout与L2正则化，性能超越KNN和简单线性探测

### 📈 性能优势
实验表明，本系统在各类测试数据集上的准确率显著高于传统方法，特别是在跨生成模型鉴别任务中表现优异，有效解决了传统模型泛化能力差的问题。


## ⚙️ 训练参数与策略

### 超参数配置
- 隐藏层结构：4层，维度分别为[2048, 1024, 512, 256]
- Dropout率：0.3（防止过拟合）
- 学习率：0.001
- L2正则化系数：0.001
- 批处理大小：128
- 训练周期：20轮
- 损失函数：二元交叉熵

### 数据增强策略
- 随机剪裁：增加模型对图像不同区域的敏感性
- 高斯模糊与JPEG压缩：模拟真实世界图像处理场景
- 颜色抖动：增强模型对色彩变化的鲁棒性
